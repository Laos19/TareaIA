TARE·IA — RF01–RF27 | PROYECTO CONFIGURADO PARA ANDROID STUDIO
==================================================================

ABRIR Y EJECUTAR EN WINDOWS (ANDROID STUDIO)
1) Clona el repositorio o extrae el proyecto en una carpeta nueva.
2) Android Studio > File > Open > selecciona la carpeta que contiene settings.gradle.
3) Settings > Build, Execution, Deployment > Build Tools > Gradle > Gradle JDK: Java 17 o 21.
   (No usar JDK 25: Gradle 8.13 no lo soporta.)
4) Asegúrate de contar con Android SDK Platform 35 y conexión para descargar dependencias.
5) File > Sync Project with Gradle Files. Selecciona tu emulador y ejecuta la configuración app (botón ▶).

COMPILAR DESDE LA TERMINAL
1) Crea local.properties en la raíz (no se versiona) con la ruta de tu SDK, por ejemplo:
     sdk.dir=C:/Users/<usuario>/AppData/Local/Android/Sdk
2) Define JAVA_HOME apuntando a un JDK 17 o 21 y ejecuta:
     gradlew.bat :app:assembleDebug
3) El APK se genera en app/build/outputs/apk/debug/app-debug.apk

VERSIONES
- Java: JDK 17 o 21
- Android Gradle Plugin: 8.13.2
- Gradle wrapper: 8.13
- Kotlin: 2.3.21 (con plugin org.jetbrains.kotlin.plugin.compose)
- Compose BOM: 2024.10.01
- Firebase BOM: 35.1.0 (Firebase Auth)
- Android compileSdk/targetSdk 35, minSdk 28

VERIFICACIÓN REALIZADA
- :app:assembleDebug compila sin errores.
- Probado en emulador Android: registro e ingreso local con PIN (incluido PIN incorrecto),
  creación y cambio de estado de actividades, persistencia tras reiniciar la app y apertura
  de todas las pantallas (Inicio, Tareas, Importar, Plan, Cursos, Horario, Apuntes,
  Sin clasificar, Papelera, Integraciones, Calendario, Reporte, Perfil, Permisos).

LÍMITES DE VERIFICACIÓN
Google Sign-In, Moodle, IA, OCR con archivos reales y exportación PDF requieren cuentas,
credenciales o archivos externos y no se han probado.

SI APARECE BUILD FAILED
  gradlew.bat :app:assembleDebug --stacktrace
Revisa la sección "* What went wrong". No aceptes una actualización automática a Gradle 9.x
para esta configuración.
