# TARE·IA — documentación técnica del código TypeScript

Detalle de **cada clase, método y propiedad** de:

- **API** (`backend/src`): Fastify + PostgreSQL. Capas: rutas → servicios → repositorios → base de datos.
- **Dashboard** (`dashboard/src`): React, cliente de la API y componentes de gráficos.
- **Servidor MCP** (`integrations/mcp/src`): herramientas para consultar TARE·IA desde Claude Code.

La documentación de la **app Android (Kotlin)** está en [../kotlin/](../kotlin/) (generada con Dokka) y los
diagramas en [../diagramas/](../diagramas/). La especificación OpenAPI se sirve en `/api/docs` de la API desplegada.
