# Inventario de skills originales archivadas

Este directorio contiene **archivos originales sin modificaciones** previamente alojados bajo `.agents/skills/`. Se mantienen por trazabilidad, pero no se consideran skills activas para el frontend Android nativo.

La aplicación `TAREIA_v4` usa Kotlin + Jetpack Compose. Las skills React, GSAP, SEO, Web Vitals, accesibilidad DOM, Terraform y presentaciones no se deben aplicar a pantallas Compose. Si se desarrolla una demo web o documentación en una fase separada, recuperar del archivo la skill correspondiente revisando antes su licencia, dependencias, rutas de ejecutables y procedencia.
